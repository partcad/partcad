# //pub/examples/partcad/feature_simulate

PartCAD example project which demonstrates simulating a part or an assembly.

## Usage
A part says what it *is*. `simulate:` is where it says what it is supposed
to **do** -- or, as here, what it is supposed not to do:

```shell
pc sim -a stable      # the stack stands; the validation passes
pc sim -a unstable    # the top block falls off; that validation passes too
pc sim                # every simulation this package declares
```

The two assemblies are the same two blocks. In `stable` the upper one sits
squarely on the lower one; in `unstable` it is pushed 18 mm out of 20 off
the edge, so its centre of mass is past the corner it rests on. Nothing
static distinguishes them -- both render, export and list the same way --
and neither does anything PartCAD can check by looking. What separates them
is what happens when the world is switched on.

Each `simulate:` states four things: the `scene:` the object is placed in
(here the default, `//builtin/scene:subject`, an empty world holding the
subject and nothing else), the `offset:` that puts it there -- the blocks
are drawn about their own centres, so the stack is lifted 10 mm to stand its
bottom face on the floor -- the `simulation:` plugin that runs it (here the
default, `//builtin/simulate:mujoco`), and the `validation:` expression that
says whether what happened is what was supposed to happen.

The two validations are opposite conditions on the very same simulation, so
both runs pass and the *results* are what differ: nothing in `stable` moves
more than a couple of millimetres in ten seconds, and something in
`unstable` ends up more than 5 mm lower than it started. `--json` prints
everything the plugin reported, which for MuJoCo is where every body was
before and after:

```shell
pc sim --json -a unstable
```

Running MuJoCo needs no MuJoCo on this machine: the plugin runs in a PartCAD
sandbox that installs it, and the scene reaches it as the MJCF PartCAD
writes. That file is an ordinary export, so it can be looked at:

```shell
pc export -S -t mjcf -O ./ //builtin/scene:subject
```
