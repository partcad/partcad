# //pub/examples/partcad/feature_export

PartCAD example project to demonstrate the 3D and CAD files `pc export` writes.

`pc export` writes the files another tool can go on working with -- meshes,
CAD kernel formats, scene formats -- and the `export:` section of
`partcad.yaml` says which of them a package publishes. Each file type is a
subsection of its own; `<file type>: <path>` is the short form of
`prefix: <path>`, which is all most of them need.

The 2D projections are the other section, `render:`, and the other example:
see `feature_render`. Only this package's own document and the picture in it
are rendered here, because every package wants those.


## Usage
```shell
pc export              # every file type below
pc export -t stl bolt  # only one of them
```
