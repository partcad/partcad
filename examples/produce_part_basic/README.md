# //pub/examples/partcad/produce_part_basic

This example demonstrates parts that are one primitive solid, declared by their dimensions alone. PartCAD writes their geometry itself, without a CAD kernel or a sandbox.

## Usage
```shell
pc ide view cube_01
pc ide view cuboid_01
pc ide view cylinder_01
pc ide view cylinder_02
pc ide view "spacer;length=25"
```
