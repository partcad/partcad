# //pub/examples/partcad/produce_sketch_wrapper

PartCAD example: sketches built by a package-defined 'sketchType'.

'sketchTypes' declares a reusable way to construct sketches, the way
'partTypes' does for parts. The 'plate' sketchType below is of the default
kind 'wrapper': its 'path' is a Python script run in the sandbox, which hands
back the sketch's faces, wires and edges. The sketches reference it with the
short form ':plate' (expanded to '<this package>:plate' when loaded), and each
sets the type's parameters to its own values.

## Usage
```shell
pc ide view -s plate
pc ide view -s plate_wide
```
