# //pub/examples/partcad/produce_scene_estates

Three historic estates of more than 20 acres each, their houses as the Historic American Buildings Survey measured them: the outside one solid, the inside its rooms' walls and furniture, on the ground where each stands.

## Usage
Each estate is a package of its own, written by `make_estate.py` from what was
read off the survey's measured drawings (`estate.json`, beside it), with the
landscape around it from the gen-landscape skill:

```shell
python3 make_estate.py site gunston_hall      # fetch the ground, grade it, write 'landscape'
python3 make_estate.py package gunston_hall   # write the house: shell, floors, rooms, furniture
```
